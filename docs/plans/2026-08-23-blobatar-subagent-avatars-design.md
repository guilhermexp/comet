# Blobatar Subagent Avatars Design

## Goal

Replace the finite Codex avatar atlas used by the Orchestrator subagent widget
with a smaller finite atlas generated by Blobatar 2.4.0.

## Architecture

Blobatar runs only as an offline development-time generator. The generated SVG
files are committed and embedded by the existing Rust/GPUI asset pipeline, so
the application gains no JavaScript runtime, network request, or package
dependency. A stable hash of the subagent row ID continues to select an avatar.

The atlas contains 28 theme-independent SVGs generated from stable seeds. The
current dark/light pairs are removed because Blobatar provides its own colors
and contrast. The row continues to render the selected asset at 14 px.

## Error handling

The build script fails when the Blobatar asset directory is missing. Tests load
and parse every generated SVG through GPUI's SVG renderer, preventing malformed
or unsupported assets from shipping.

## Validation

- Selector tests prove stable distribution and theme-independent paths.
- Asset tests prove the exact atlas count and GPUI SVG compatibility.
- Focused UI tests run during TDD, followed by the repository's canonical UI
  test gate and a debug build.
