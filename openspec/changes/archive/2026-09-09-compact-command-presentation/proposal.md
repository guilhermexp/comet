## Why
Command headers expose long monospaced invocations and expanded output is detached from its header. Reasoning bodies lack the reference indentation rule.

## What Changes
Use Ran command/Running command with a short sans detail, one framed header and payload when expanded, and an inset rule for reasoning. Preserve full invocation, output, disclosure choices, active-only spiral, and final-only totals.

## Capabilities
### Modified Capabilities
- `turn-step-tool-groups`: compact command presentation and reasoning body hierarchy.

## Impact
Native UI presentation only; no execution or persisted data changes.
