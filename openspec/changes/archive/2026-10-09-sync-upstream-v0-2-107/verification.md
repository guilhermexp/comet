## Failures diagnosed during integration

1. Compile errors from fork-only `RunRequest`, Session and ProcessRequest fields, renamed runtime controls and API tuple extensions were repaired in production callers and live-test literals. The all-targets check verifies callers enabled by the default and appshots-fixture features; the gated Pi native fixture is compiled and exercised separately.
2. SQLite maintenance consumed repeated busy waits under another connection's write lock. Measured operations took roughly 1.5–2 seconds each despite the nominal 250 ms timeout. Maintenance now uses zero busy timeout and yields immediately; normal store operations retain five seconds. Original deadlines remain unchanged, with an additional open-connection assertion.
3. Snapshot cancellation originally killed only the Git leader, leaving a clean-filter descendant. Snapshots now use the existing ProcessRunner process-group ownership. A second review found stdin could delay the stdout cap; coordination now kills on output cap while stdin is blocked. Both receive targeted regressions.
4. Worker notices were not drained after Stop froze the ordinary queue. Redrain occurs after releasing the lock, with the frozen queue preserved. A separate fake-runner race subscribed to completion after publishing its prompt; ordering is corrected without changing deadlines. The initial frozen-queue fixture used a Worker-like ID but omitted the required `[worker-task-notification]` prefix; it was therefore an ordinary message. The corrected regression uses both genuine markers and an unsteerable TurnBoundary runtime. Review then found Stop could cancel the genuinely held notice through `steered_rows`; final correction and evidence are recorded below.
5. The OpenCode bounded-timeout test had two distinct failure sites. The earlier attempt failed in the Done helper; an attempted fixture pause-before-request then introduced a setup failure. Final logs locate the latter at TurnWire::request (line 364), before the POST receipt barrier and before advance(61s), not in Done. Paused Tokio automatically advances the five-second setup guard while OS HTTP I/O is pending. The corrected fixture waits for the server to receive the body with real time, then pauses and advances past the unchanged deadline. The harness owns an outer 60-second deadline across the complete POST (alongside reqwest). Review separately confirmed swallowed body transport errors could leave a turn open; they now propagate through CommandFailed to Done(Errored). The truncated-body and valid-empty-204 regressions passed in the 401-pass/one-setup-failure unit run; the corrected deadline regression passed in the subsequent 401-pass/one-Claude-timing-failure unit run; focused final acceptance follows below. No Reqwest defect is claimed.
6. The OMP oversized-frame fixture needlessly translated nine MiB through `tr`. It now emits the same oversized no-newline frame directly, preserving the byte cap and original two-second deadlines; final integration confirmed it passes. A new inline-image steer test initially failed because its fake expected the wrong Base64 continuation (`...go` rather than `...gp` for the signature followed by fixture bytes). The fake now compares the complete correct payload, including its terminating JSON quote; production image delivery was already correct.
7. Initial iOS core build used Homebrew rustc without the iOS stdlib. The corrected command explicitly selects the installed rustup toolchain and simulator target.
8. Initial punctuation commands used the root workspace, which omits the vendor crate's dev dependency graph. The successful manifest command uses the vendor workspace and its local patches; the generated test-only vendor lockfile change was restored.

9. UI test compilation exposed upstream constructor fields and GPUI harness APIs that differ from the fork. The fixes distinguish durable MessagePart from renderer ToolItem, retain the fork Session fields, make the file badge stateful before wiring clicks, and use VisualTestContext correctly. The native fixture also needs the fork WorkersModel argument in Shell construction. These failures occurred before functional tests executed; the final reruns below supersede them. The first exact editor-test filter selected zero cases and is not counted as evidence.

Independent review also required process-bound MCP grants to invalidate persistent runtimes, OMP image follow-ups to retain inline attachments, and finished subagents to start collapsed.
