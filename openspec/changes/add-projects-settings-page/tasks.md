## 1. The ledger

**must_haves:** a `remove_project` call cannot take a ledger entry with it; an unmodelled top-level key in `app-state.json` survives every ledger write; the same folder re-added keeps its original added date; nothing here touches the working-set `projects` array.

- [x] C1 New `crates/workers-unpeel/src/project_ledger.rs`: `LedgerProject { path, name, added_at_unix_ms, last_seen_at_unix_ms, icon_path }` plus read/write over the `comet_projects` key via `unpeel_core::app_state::{load, edit}`. Keyed by canonical path (D-03); `edit` is the only writer so the flock and the key-preservation guarantee both apply. Unit-test that a write into a document carrying an unknown top-level key leaves that key intact. files: `crates/workers-unpeel/src/project_ledger.rs`, `crates/workers-unpeel/src/lib.rs`. verify: `cargo test -p zeron-workers-unpeel project_ledger`.
- [x] C2 `reconcile(ledger, working_set, now) -> Vec<ProjectRow>` as a **pure** function over already-loaded data: live rows join on canonical path and refresh `last_seen_at`, unseen working-set paths mint a ledger row with `added_at = now`, ledger-only rows keep their frozen values and carry no project id. Unit-test all three branches plus the re-add case (ledger-only path becomes live under a NEW id and keeps the ORIGINAL `added_at`). files: `crates/workers-unpeel/src/project_ledger.rs`. verify: `cargo test -p zeron-workers-unpeel project_ledger`.
- [x] C3 `WorkersClient::projects_with_ledger()` — one `bootstrap()`, then C2 over its projects, then persist the mutations C2 decided (new rows, refreshed `last_seen_at`). Last-opened for a live row is `max(session.updated_at_unix_ms)` over the bootstrap sessions (D-05); for a ledger-only row it is `last_seen_at`. Red-capable check: a test that removes a project through `remove_project` and asserts the ledger row is still readable afterwards — this is the whole point of the change and must fail if the ledger key ever moves under `projects`. files: `crates/workers-unpeel/src/lib.rs`, `crates/workers-unpeel/src/project_ledger.rs`. verify: `cargo test -p zeron-workers-unpeel`.
